## AI assistance

On November 14, 2026, OpenAI Codex assisted with rules research, repository scaffolding, Gradle configuration, Java implementation, HUD/console design, the teacher dashboard and backend foundation, and documentation, including expanding the team's ideas into `PLAN.md`, maintaining `TODO.md`, and producing the internal `JUDGE_REVIEW.md` critique. The team supplied the challenge choice, Minecraft mod format, Minecraft 26.3 / Java 25 requirement, teacher platform, cooperative roles, Mars exploration, NPC dialogue, and task minigame direction. Assistance is also declared in `fabric.mod.json` under `custom.ai_assistance`; this file is included in the built JAR.

Carry this disclosure into the competition submission's AI/SI field. Update it as work continues. Generated images/video require visible generation labels under the submission guide. The eight 16×16 item sprites and 64×32 worn armor layers are original, programmatically drawn pixel artwork created with Codex assistance. They live under `src/main/resources/assets/nimbus_nova/textures`. Aster Outpost is an original arrangement of vanilla blocks in an authored dimension, generated by `MarsTrainingMap`; no external world download or texture pack was copied. Do not treat their presence as NASA imagery or an accurate Mars reconstruction.

## Future science sources

When adding NASA data, record the exact dataset/study URL, retrieval date, units, transformations, use terms, and which mechanic uses it. Label archived data as archived and game balance values as simplified assumptions. An Earth-directed space-weather alert is not a calibrated lunar or Mars surface radiation dose. The current four-minute mission rates, dust timing, and equipment capacities are authored game balance. NASA data integration remains pending until an exact source and transformation are documented.

## Rendering and font

The Nova renderer uses original RenderPearl/Blaze3D GUI render states and shaders. Sapphire in the team's existing mod informed the design; its engine implementation was not copied. The bundled Geist MTSDF atlas is derived from [Geist](https://github.com/vercel/geist-font), licensed under SIL OFL 1.1; the full license is bundled at `assets/nimbus_nova/fonts/OFL.txt`. RGB-median distance reconstruction follows the technique documented by [msdf-atlas-gen](https://github.com/Chlumsky/msdf-atlas-gen). The font software remains under OFL, separately from the repository's MIT code.
